# City Builder — Phase 1

A modular Three.js/WebGL browser prototype.

## Run

Because this project uses ES Modules, serve the folder with a local HTTP server rather than opening `index.html` directly.

Examples:

- VS Code + Live Server
- `python -m http.server 8000`
- Any static web server

Then open `http://localhost:8000/`.

## Phase 1 implemented

- Three.js scene and WebGL renderer
- Procedural low-poly terrain
- Build grid
- Water/shore area
- Trees and city boundary
- Isometric-style camera
- Orbit, pan, zoom
- WASD / arrow camera movement
- Camera boundary limits
- Dark glass UI
- Money / population / happiness / balance HUD
- Toolbar foundation
- Simulation clock
- Pause / play / fast-forward controls
- Modular architecture placeholders for later phases
