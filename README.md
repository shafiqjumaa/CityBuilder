# Prompt Vault

مكتبة شخصية لإدارة البرومبتات، بواجهة عربية RTL ومظهر داكن، وتحليل جماعي تلقائي عبر OpenAI أو Gemini أو Claude.

## ما يعمل في النسخة الحالية

- واجهة عربية RTL متجاوبة.
- إضافة عدة برومبتات في دفعة واحدة؛ افصل بينها بسطر `---`.
- تحليل آلي لاسم البرومبت وشرحه وتصنيفه والكلمات المفتاحية والأداة المناسبة.
- حفظ النص الأصلي كما هو.
- بحث في الاسم والشرح والنص والكلمات المفتاحية.
- تصنيفات، مفضلة، آخر الإضافات، تحديد متعدد.
- تعديل وحذف ونسخ وتصدير JSON واستيراد JSON.
- تخزين محلي تلقائي في المتصفح.
- إعدادات API لثلاثة مزودين.
- دالة Cloudflare Pages Function وسيطة لطلبات التحليل.
- مزامنة اختيارية إلى Supabase باستخدام Anonymous Auth وسياسات RLS.

## التشغيل محلياً

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. لتجربة دالة التحليل محلياً مع Cloudflare Pages:

```bash
npm run build
npx wrangler pages dev dist
```

ثم أضف مفتاح API من داخل الإعدادات. المفتاح يبقى في ذاكرة الصفحة ولا يُحفظ في localStorage أو قاعدة البيانات. كل طلب تحليل يمر عبر `/api/analyze`.

## النشر على Cloudflare Pages

1. ارفع المشروع إلى مستودع GitHub جديد.
2. من Cloudflare Dashboard اختر **Workers & Pages → Create → Pages → Connect to Git**.
3. اختر المستودع.
4. Build command: `npm run build`
5. Build output directory: `dist`
6. انشر المشروع. مجلد `functions/` سيُستخدم تلقائياً كـ Pages Functions.

لا تحتاج إلى وضع مفتاح AI في إعدادات Cloudflare في هذا الإصدار؛ أدخله من واجهة الإعدادات عند فتح الموقع. لا تحفظ المفتاح في جهاز مشترك، ولا تشارك الجلسة أثناء إدخاله.

## إعداد Supabase (اختياري)

1. أنشئ مشروع Supabase.
2. من Authentication → Providers فعّل Anonymous Sign-ins.
3. نفّذ `supabase/schema.sql` من SQL Editor.
4. من Settings → API انسخ Project URL والمفتاح العام `publishable` أو `anon`.
5. أدخل القيم في الإعدادات واضغط «مزامنة المكتبة الآن».

**تنبيه:** المزامنة الحالية ترفع العناصر الموجودة في الجهاز إلى حساب مجهول. لا تنفذ دمجاً ثنائياً أو تنزيل العناصر من السحابة تلقائياً بعد؛ لذلك استخدم جهازاً/متصفحاً واحداً للمزامنة في هذه النسخة الأولية. التخزين المحلي يظل هو المصدر الأساسي.

## ملاحظات أمان وحدود

- لا تستخدم مفتاح Supabase `service_role` في الواجهة.
- لا تضع مفاتيح API في ملفات المشروع أو GitHub.
- مفتاح مزود AI يبقى في ذاكرة الصفحة فقط، لكنه يُرسل عبر HTTPS إلى دالة الموقع ثم إلى مزود الخدمة.
- التحليل يقبل 1–30 برومبتاً في الطلب الواحد، وبحد 30,000 حرف لكل برومبت.
- قد تختلف أسماء النماذج المتاحة حسب حساب المزود؛ غيّر قيمة Model من الإعدادات عند الحاجة.
- النسخة الحالية تحفظ محلياً تلقائياً؛ لا يوجد تسجيل دخول تقليدي أو مشاركة بين المستخدمين.
